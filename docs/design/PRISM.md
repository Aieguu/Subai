# Prism · 棱镜

> 一束白光，折射成可读的层次。

Subai 主题的第二代设计语言，面向年轻读者与开发者。用于替换 v1「纸 · 墨 · 朱砂」。
本文是规范，不是提案讨论——所有数值都是可直接落进 `assets/css` 的终值。

---

## 0. 与 v1 的关系

v1 是「纸墨编辑体」：暖纸底、衬线标题、发丝线、极克制。它好看，但有三个问题：
默认表情偏成熟（像文学刊物而非技术博客）、浅色才是被设计的那一面、圆角与间距
密度偏保守，在 2026 年的屏幕上显得旧。

v2 **不推翻 v1 的骨架，只换它的光**：

| 维度 | v1 纸墨朱砂 | v2 Prism |
| --- | --- | --- |
| 隐喻 | 纸（载体）· 墨（内容）· 朱砂（强调） | 光（载体）· 折射（层次）· 棱镜（品牌） |
| 主设计面 | 浅色（暖纸 #FAF9F6） | **深色（石墨 #0C0D11）** |
| 强调色 | 朱砂 #A63D2A（暗砖红） | 电光朱 #F5451F（高饱和朱，同一色相提亮提纯） |
| 标题字 | 衬线（Noto Serif SC 600） | 无衬线紧字距（Geist / Inter + 系统中文黑体） |
| 字阶模数 | 1.333，17px 基准 | 1.25，UI 15px / 阅读 17px 双档 |
| 圆角 | 3 / 6 / 8 / 10 / 14 | 6 / 8 / 12 / 16 / 20 / 28 |
| 层次手段 | 1px 发丝线，卡片不用投影 | 表面明度阶梯 + 1px 描边 + 极柔双层阴影 |
| 动效曲线 | expo.out 单一曲线 | 入场用缓出、按压用弹簧、其余机械缓动 |
| 装饰 | 印章、墨圈、洇墨、山水频谱 | 折射棱、颗粒噪点、硬边朱印；纸墨细节**保留但换材质** |
| 元信息 | 与正文同字体 | 等宽字体（日期/字数/标签/分类） |

强调色刻意沿用「朱」这一色相——品牌有连续性，读者不会认不出是同一个站。

## 0.5 反 AI 审美清单（硬约束，优先于下文一切条目）

「年轻 + 现代」极易滑向 AI 生成风格的平均值：紫蓝渐变、玻璃拟态、霓虹发光、
万物大圆角、到处弹跳。这套指纹要系统性排除。判断标准只有一条：
**这个处理有没有具体来源？** 说不出来源的装饰一律删。

### 明令禁止

| 禁止项 | 说明 |
| --- | --- |
| 紫蓝 / 彩虹渐变 | 最常见的 AI 指纹。全站零渐变，例外见下 |
| 玻璃拟态 `backdrop-filter` | 顶栏用实色 + 底部 hairline，不做模糊 |
| Aurora / mesh 光斑背景 | 已删除（原设计的「光晕」）——质感交给噪点 |
| 霓虹发光 `--glow-accent` | 已删除。彩色投影是廉价未来感 |
| 渐变文字 `background-clip: text` | 禁 |
| 万物 `999px` 圆角 | 圆角上限收到 16px，`full` 只给头像与圆形图标钮 |
| Emoji 当图标 | 禁。图标一律 Lucide |
| 粉彩低对比 | 所有色值必须过 WCAG AA |
| 到处弹簧回弹 | 弹簧只给 `:active` 按压反馈，其余用机械缓动 |
| 无来源的浮动装饰几何 | 装饰必须承载品牌语义（折射棱 / 印章 / 时辰） |

### 替代手法（这些是有来源的，不是平均值）

- **瑞士国际主义网格**——强对齐、模块化栏宽、靠 hairline 规则线分栏而非色块。
  参考系是 Swiss poster / 现代期刊，不是「好看的卡片」。
- **等宽字体做元信息**——时间、字数、标签、分类、代码块语言标、导航次级文字
  一律 JetBrains Mono。这是 AI 几乎不会做的真设计师手法，且天然贴合开发者博客。
- **硬边偏移阴影**——个别组件（激活态、印章）用**无模糊的实心偏移**（`2px 2px 0`），
  而不是柔和投影。硬边 = 有态度。
- **噪点而非渐变**——质感用 `feTurbulence` 颗粒，不用光斑。
- **Risograph 油墨色谱**——折射色取孔版印刷油墨的色感（见 §2.3），
  而非糖果荧光色。油墨是有实物参照的，糖果色没有。

## 1. 核心理念（四条，用于裁决争议）

1. **暗底为家（Dark-native）**
   深色不是浅色的反色，是主设计面。所有组件先在深色上画好，再推浅色版。
   浅色版不是「把颜色反过来」，而要重新调阴影、描边与表面明度。

2. **一束强光（One vivid accent）**
   全站只有一个高饱和强调色。其余全是带冷偏的石墨灰阶。
   强调色只允许出现在三种语义上：**可点击 / 当前所在 / 需要注意**。
   拿不准某个元素该不该用强调色时——不用。

3. **折射出层次，而不是涂色块（Refraction, not decoration）**
   层次靠表面明度阶梯（sunken → base → raised → overlay）+ 1px 描边 + 极柔双层阴影表达。
   渐变只允许出现在「光本身」：焦点光晕、进度、激活态、插画。
   **禁止**给卡片铺大面积渐变、禁止彩虹配色。

4. **动效要有来处与去处（Motion with provenance）**
   每一次动画都必须回答「这个东西从哪来、到哪去」。答不上来的动画删掉。
   交互反馈用弹簧（有回弹 = 有物理感），入场用缓出（有方向 = 有来源）。
   不做无意义的弹跳、摇摆、循环呼吸。

## 2. 色彩系统

### 2.1 石墨灰阶 Graphite（中性色，带冷偏）

冷偏而非纯灰，是为了让「光」的隐喻成立——中性色是阴影，不是纸。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--p-graphite-0` | `#FFFFFF` | 浅色最高表面 |
| `--p-graphite-50` | `#F7F8FA` | 浅色页面底 |
| `--p-graphite-100` | `#EFF1F5` | 浅色次级表面 |
| `--p-graphite-200` | `#E2E5EC` | 浅色描边/分隔 |
| `--p-graphite-300` | `#CBCFD9` | 浅色禁用描边 |
| `--p-graphite-400` | `#9AA0AF` | 占位符 / 弱化图标 |
| `--p-graphite-500` | `#6E7484` | 次级文字（浅）/ 三级文字（深） |
| `--p-graphite-600` | `#525866` | 深色次级文字 |
| `--p-graphite-700` | `#3A3F4B` | 深色描边 |
| `--p-graphite-800` | `#24272F` | 深色浮层 / 代码底 |
| `--p-graphite-900` | `#15171C` | 深色卡片底 |
| `--p-graphite-950` | `#0C0D11` | 深色页面底 |

### 2.2 电光朱 Volt（强调色，唯一）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--p-volt-50` | `#FFF1EE` | 浅色强调底（选中行） |
| `--p-volt-100` | `#FFE0D9` | 浅色强调底（hover） |
| `--p-volt-200` | `#FFC4B6` | 浅色强调描边 |
| `--p-volt-300` | `#FF9E88` | 深色上的次级强调 |
| `--p-volt-400` | `#FF7253` | **深色模式主强调**（对比度更够） |
| `--p-volt-500` | `#F5451F` | **色相核心 / 浅色模式主强调** |
| `--p-volt-600` | `#D8320F` | hover / 按压 |
| `--p-volt-700` | `#A8250C` | 深色上的强调文字（低亮背景时） |

- 浅色模式主色用 **500**，文字/小图形一律 600 及以上（500 在白底上对比度不足）。
- 深色模式主色用 **400**，图形可用 500，文字用 300/400。
- 强调色**不用于**正文、标题、大段背景。

### 2.3 折射色 Flux（光谱色，受限使用）

棱镜把光拆成光谱——这组色只服务于「分类/标签/数据」这类需要**区分**的场景，
是数据色，不是装饰色。

色感取自**孔版印刷（Risograph）油墨**而非糖果荧光色：略降彩度、带一点油墨的浑浊感。
糖果色没有实物参照，油墨有。深色模式下用提亮变体，否则在近黑底上会发闷。

| 令牌 | 浅色值 | 深色值 | 建议语义 |
| --- | --- | --- | --- |
| `--p-flux-cyan` | `#2BB8C4` | `#4FD0DC` | 前端 / Web |
| `--p-flux-indigo` | `#5A5FE0` | `#8B8FF5` | AI / ML |
| `--p-flux-moss` | `#7FA83A` | `#A3C95C` | 工具链 / 效率 |
| `--p-flux-ochre` | `#C8862B` | `#E0A24E` | 运维 / 部署 |
| `--p-flux-rose` | `#D9536F` | `#EE7A90` | 随笔 / 生活 |

**硬约束**：折射色只能出现在标签 chip 的 6px 圆点、分类卡顶部 3px 色条、
图表与代码块语言标描边。不得用于正文文字、按钮、链接、大色块、渐变。

### 2.4 语义色

降饱和，避免和强调色抢注意力。

| 令牌 | 浅色 | 深色 |
| --- | --- | --- |
| success | `#1F9254` | `#54D18A` |
| warning | `#B26A00` | `#FFB020` |
| danger | `#D92D20` | `#FF6B5E` |
| info | `#2563C9` | `#5B9BFF` |

### 2.5 表面阶梯（elevation）— 层次的主手段

| 语义令牌 | 浅色 | 深色 |
| --- | --- | --- |
| `--color-bg-sunken` | `#F7F8FA` | `#0C0D11` |
| `--color-bg` | `#FFFFFF` | `#15171C` |
| `--color-bg-raised` | `#FFFFFF` | `#1D2028` |
| `--color-bg-overlay` | `#FFFFFF` | `#24272F` |
| `--color-bg-inset`（输入框/代码） | `#F2F4F7` | `#0F1115` |

浅色下 sunken 与 raised 几乎同亮 → 浅色模式**必须**靠描边和阴影区分层次；
深色下靠明度阶梯本身就够 → 深色模式描边可以更淡。这是两种模式不是简单反色的原因。

## 3. 字体与字阶

### 3.1 字体栈

```css
--font-family-sans: 'Geist', 'Inter', system-ui, -apple-system,
                    'PingFang SC', 'HarmonyOS Sans SC', 'Microsoft YaHei',
                    'Noto Sans CJK SC', sans-serif;
--font-family-mono: 'JetBrains Mono', 'SF Mono', 'Cascadia Code',
                    Consolas, monospace;   /* 沿用 v1，已自托管 400/500 */
```

- **Latin/UI：Geist**（OFL 1.1，可变字重，几何偏中性，2026 年开发者圈主流审美）。
  若对 Geist 的可用性有顾虑，Inter 是等价替代（同为 OFL、同为中性无衬线）。
- **中文：不自托管。** 走系统栈（苹方 / 鸿蒙 / 微软雅黑 / 思源）。
- **等宽字体做元信息（关键的反 AI 手法）**：日期、字数、标签、分类、代码块语言标、
  导航次级文字、页脚版权行一律 `--font-family-mono`，配合 12–13px 与 `0.04em` 字距。
  AI 生成的设计几乎从不这么做，而它是真实设计里的常见手法，且天然贴合开发者博客。
  正文与标题**不用**等宽。
  这是与 v1 最大的工程差异：v1 自托管了 104 个 Noto Serif SC 分片 woff2。
  v2 改无衬线后，自托管中文的收益（衬线气质）消失，只剩体积负担 → **去掉**。
  预计 `static/fonts/` 从 104 个文件降到 3–4 个（Geist latin 可变 + JetBrains Mono 400/500）。
- 数字、代码、时间、字数统计一律等宽。

### 3.2 双档字阶（UI 密度 ≠ 阅读密度）

v1 用一套 17px 打天下，导致侧边栏、标签、元信息偏大。v2 拆两档：

**UI 档**（导航、卡片元信息、按钮、表单）基准 15px，模数 1.25：

| 令牌 | 值 |
| --- | --- |
| `--font-size-ui-xs` | 0.75rem / 12px |
| `--font-size-ui-sm` | 0.8125rem / 13px |
| `--font-size-ui-base` | 0.9375rem / 15px |
| `--font-size-ui-lg` | 1.0625rem / 17px |

**阅读档**（正文、标题、长文）基准 17px，模数 1.25：

| 令牌 | 值 | 行高 |
| --- | --- | --- |
| `--font-size-sm` | 0.875rem / 14px | 1.7 |
| `--font-size-base` | 1.0625rem / 17px | **1.8** |
| `--font-size-lg` | 1.25rem / 20px | 1.7 |
| `--font-size-xl` | 1.5rem / 24px | 1.5 |
| `--font-size-2xl` | 1.875rem / 30px | 1.35 |
| `--font-size-3xl` | 2.25rem / 36px | 1.25 |
| `--font-size-4xl` | `clamp(2.5rem, 5vw, 3.25rem)` | 1.15 |

正文 17px / 1.8 **保持不变**——这是 v1 为中文长文调过的，实测舒服，不动。

### 3.3 字重与字距

- 字重只留 400 / 500 / 600 / 700 四档。标题 600，不用 700（现代无衬线 600 已够分量）。
- 标题字距 `letter-spacing: -0.02em`（Latin）；中文标题 `-0.01em`，中文正文 `0`。
  负字距是现代感的关键，v1 完全没有。
- 正文行高 1.8，段落间距 `1.25em`；中英混排自动加 `0.05em` 间隙
  （用 `text-autospace`，退化时忽略）。

### 4.1 间距（4px 网格）

| 令牌 | 值 |
| --- | --- |
| `--space-0` | 0 |
| `--space-1` | 0.25rem / 4px |
| `--space-2` | 0.5rem / 8px |
| `--space-3` | 0.75rem / 12px |
| `--space-4` | 1rem / 16px |
| `--space-5` | 1.25rem / 20px |
| `--space-6` | 1.5rem / 24px |
| `--space-8` | 2rem / 32px |
| `--space-10` | 2.5rem / 40px |
| `--space-12` | 3rem / 48px |
| `--space-16` | 4rem / 64px |
| `--space-20` | 5rem / 80px |
| `--space-section` | `clamp(3rem, 6vw, 5rem)` |

卡片内边距统一 `--space-6`（24px）；卡片网格间距 `--space-4`（16px），移动端 `--space-3`。

### 4.2 圆角（明显放大，这是「年轻」最直接的杠杆）

上限收到 16px。原方案里的 20 / 28 已删除——那是泡泡感，是 AI 指纹。
`full` 只给头像和圆形图标钮两处，不给卡片、按钮、搜索框。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--radius-xs` | 4px | chip、徽标 |
| `--radius-sm` | 6px | inline code、小控件 |
| `--radius-md` | 10px | 按钮、输入框、搜索框 |
| `--radius-lg` | 12px | 卡片 |
| `--radius-xl` | 16px | 大卡片、浮层、模态 |
| `--radius-full` | 999px | 仅头像与圆形图标钮 |

### 4.3 阴影（双层：ambient + key）

```css
/* 浅色 */
--shadow-1: 0 1px 2px rgb(12 13 17 / 0.05), 0 1px 1px rgb(12 13 17 / 0.04);
--shadow-2: 0 4px 8px -2px rgb(12 13 17 / 0.08), 0 2px 4px -2px rgb(12 13 17 / 0.06);
--shadow-3: 0 12px 24px -6px rgb(12 13 17 / 0.10), 0 4px 8px -4px rgb(12 13 17 / 0.06);
--shadow-4: 0 24px 48px -12px rgb(12 13 17 / 0.18), 0 8px 16px -8px rgb(12 13 17 / 0.08);

/* 深色：阴影减弱，层次交给明度阶梯与描边 */
--shadow-1: 0 1px 2px rgb(0 0 0 / 0.30);
--shadow-2: 0 4px 8px -2px rgb(0 0 0 / 0.40);
--shadow-3: 0 12px 24px -6px rgb(0 0 0 / 0.50);
--shadow-4: 0 24px 48px -12px rgb(0 0 0 / 0.60);

/* 硬边偏移：无模糊实心，只给激活态与印章——硬边是有态度，柔光是廉价未来感 */
--shadow-hard: 2px 2px 0 0 var(--color-primary);
--shadow-hard-sm: 1px 1px 0 0 var(--color-primary);
```

- 卡片**默认只用 `--shadow-1` 或不用**，hover 才升到 `--shadow-2`。
- **没有彩色发光。** 原方案的 `--glow-accent` 已删除（见 §0.5），
  需要「强调」时用实色偏移 `--shadow-hard` 或 2px 实色描边，不用投影发光。

### 4.4 描边与焦点环

```css
--border-width-hairline: 1px;
--border-color:        rgb(12 13 17 / 0.09);   /* 浅色 */
--border-color-strong: rgb(12 13 17 / 0.16);
--border-color:        rgb(255 255 255 / 0.10); /* 深色 */
--border-color-strong: rgb(255 255 255 / 0.18);

--ring-width: 2px;
--ring-offset: 2px;
--ring-color: var(--color-primary);
```

- 1px 发丝线是 v1 的品牌基因，**保留**；深色下换成半透明白，而不是灰色。
- 焦点环 2px + 2px offset，键盘可见性是现代主题的及格线，v1 这块弱，v2 必须补齐。

## 5. 图标与插画

### 5.1 图标

- **统一到 Lucide**：24px 网格、2px 描边、`round` cap/join、几何简化、ISC 许可。
  v1 用了 1.8 描边且来源混杂（Iconfont 音乐图标、内联手写 SVG），视觉不齐。
- 选中/激活态用**实心（filled）变体**，与描边态形成明确 dual-tone——这是现代图标系统
  表达「当前所在」的主流做法，也比只换颜色更友好。
- 保留 v1 WIP 里的 `pathLength="1"` 约定（日月图标笔顺画出），这套手法在 v2 继续用。
- 音乐播放器的 6 个 Iconfont 图标保留（有作者署名，README 已致谢），但统一到 24px 网格。

### 5.2 插画与纹理

- **颗粒噪点（grain）**：`feTurbulence` 生成的 SVG 噪声，1.5% 透明度铺在页面底。
  这是**唯一**允许的质感来源——消除纯色平面的廉价感，且它是实物参照（纸张/印刷网点），
  不是渐变光斑。原设计的 aurora 光晕背景已删除。
- **折射棱**：品牌图形母题——三角棱柱把一束白光拆成 2–3 道光谱细线，**硬边实色**，
  不做发光不做渐变。用在 404、空状态、印章替代物。
- **404**：v1 的「一笔未合拢的墨圈」→ v2 的「断棱光环」：一道折射光环被打断，
  配文「这里没有光」。结构一致（单笔 SVG 描边 + 糙边滤镜），只换材质。
- **印章**：v1 的朱砂篆刻印 → v2 的「朱印」：同样竖排 1–2 字，底色改电光朱实色 +
  `1px 1px 0` 硬边偏移（不是外发光），糙边保留。纸墨细节因此得以延续而不是被删掉。

## 6. 组件外观

### 6.1 按钮

| 尺寸 | 高度 | 内边距 | 圆角 | 字号 |
| --- | --- | --- | --- | --- |
| sm | 36px | 0 14px | 10px | 13px |
| **md（默认）** | **44px** | 0 18px | 10px | 15px |
| lg | 52px | 0 24px | 12px | 17px |

- **Primary**：实心电光朱底、白字、**无发光**；hover 加深到 600 并上浮 1px；
  active 用 `--ease-spring` 做 `scale(0.97)` 回弹（弹簧只在这里用）。
- **Secondary**：`--color-bg-raised` 底 + 1px 描边 + 主文字色；hover 描边转 strong。
- **Ghost**：透明底；hover 加 `--color-bg-raised`。
- **Danger**：语义 danger 色，形制同 Primary。
- **IconButton**：40×40，圆角 10，图标 20px。
- 44px 是触控及格线（v1 的按钮普遍偏矮），这条必须达标。
- 焦点：2px 电光朱环 + 2px offset。**禁用**：opacity 0.5 + `cursor: not-allowed`，
  不要只靠变灰（对比度不足）。

### 6.2 卡片

- 圆角 12（大卡 16）、1px 描边、`--color-bg-raised` 底、`--space-6` 内边距。
- 默认**无阴影或 `--shadow-1`**；hover 时描边转 strong + `translateY(-2px)` + `--shadow-2`。
- 封面图 16:10，圆角继承卡片，`overflow: hidden`，hover 时图片 `scale(1.03)`。
- 按压 `scale(0.995)`。
- 卡片里的**标题用主文字色，不用强调色**；hover 时标题下方扫入 2px 电光朱下划线
  （沿用 v1 的 `background-size` 手法，只换颜色与粗细）。
- **Bento 网格**：沿用 v1 首页 mosaic 的分块思想，但间距统一 16px、圆角 16、
  每块加描边与独立表面色——v1 的磁贴靠留白区分，v2 靠表面区分，块更「实」。

### 6.3 表单

- 输入框高 44px、圆角 10、`--color-bg-inset` 底、1px 描边。
- 标签在上方，13px、`--color-text-secondary`；不用浮动标签（长表单易跳）。
- 占位符用 `--p-graphite-400`，绝不用占位符替代标签。
- 聚焦：描边转电光朱 + 2px 外环，背景微微提亮到 `--color-bg-raised`。
- 错误：描边转 danger + 左侧图标 + 下方 13px 说明文字。
  **三重编码（颜色 + 图标 + 文字）**，不靠颜色单打独斗。
- **搜索框**：`--radius-md`（10px）、44px、前置放大镜图标、右侧显示 `⌘K` 提示 chip。
  刻意**不**用胶囊形——满屏胶囊是 AI 指纹。
  ⌘K 快捷键是年轻开发者群体的肌肉记忆，成本极低、感知极强。

### 6.4 导航

- 顶栏：高 64px（桌面）/ 56px（移动），**实色底 + 底部 hairline**，不用
  `backdrop-filter`（玻璃拟态是 AI 指纹，见 §0.5）。滚动后分隔线加重并压上 `--shadow-1`。
- 当前项：文字色 + 下方 2px 电光朱指示条（v1 只靠颜色，辨识度弱）。
- 移动端菜单：从底部上滑的 sheet，圆角顶部 20，带遮罩，支持下滑关闭。

### 6.5 其他

- **标签 chip**：圆角 4px（不是胶囊）、12px 等宽字、浅色底 + 对应折射色圆点 6px。
- **代码块**：`--color-bg-inset` 底、圆角 12、1px 描边；语言标签用折射色；
  复制按钮 Ghost 尺寸 sm，只在 hover/focus 时完全显现。
- **TOC**：1px 竖向轨道 + 当前项 2px 电光朱指示，缩进靠 padding 而非嵌套列表。
- **分页**：圆角 12 方块，当前页实心电光朱，禁用页 opacity 0.4。

## 7. 动效原则

### 7.1 曲线（分工明确，不再一条曲线打天下）

```css
--ease-out:      cubic-bezier(0.22, 1, 0.36, 1);      /* 入场：有方向 */
--ease-in-out:   cubic-bezier(0.4, 0, 0.2, 1);        /* 位移/形变 */
--ease-standard: cubic-bezier(0.2, 0, 0, 1);          /* 颜色/透明度、hover */
--ease-snap:     cubic-bezier(0.32, 0.72, 0, 1);      /* 菜单/浮层收放：快、机械 */
--ease-spring:   cubic-bezier(0.34, 1.56, 0.64, 1);   /* 仅 :active 按压回弹 */
```

`--ease-spring` **只允许用在 `:active` 按压反馈上**。处处回弹是 AI 的「愉悦感」套路，
也让人觉得界面在撒娇。hover、入场、浮层一律机械缓动。

### 7.2 时长

| 令牌 | 值 | 场景 |
| --- | --- | --- |
| `--duration-micro` | 100ms | 颜色、透明度切换 |
| `--duration-fast` | 160ms | hover、按压 |
| `--duration-base` | 240ms | 菜单展开、卡片上浮 |
| `--duration-slow` | 400ms | 页面元素入场 |
| `--duration-deliberate` | 640ms | 主题切换、模态 |

- 列表入场 stagger **40ms**，封顶 8 项（v1 是 60ms/8 项，v2 更紧凑）。
- 主题切换沿用 v1 的 View Transitions 圆形展开，时长从 200ms 提到 320ms，
  圆心取触发按钮位置（v1 取屏幕中心，逻辑上「从按钮长出来」更成立）。

### 7.3 规则

1. 动效必须能回答「从哪来、到哪去」，答不上来就删。
2. **同一屏只有一个焦点在动**——列表入场时不要同时跑进度条动画。
3. hover 用 standard（快、无戏剧性）；**只有 `:active` 按压**才允许弹簧回弹；
   入场/离场用缓出；浮层收放用 snap。
4. 页面切换（PJAX）：淡入 + 上移 6px，160ms。
   v1 的「墨散于水」模糊晕染好看但慢，v2 要更利落。
5. 全部尊重 `prefers-reduced-motion`：降级为**直接呈现终态**，不是「动画时长归零」。
6. 不做循环动画（呼吸、漂浮），除非是加载/播放中的状态指示。

## 8. Design Tokens 落地方案

### 8.1 三层结构

```
第 1 层  原始层  --p-*        色板/字阶/间距/圆角/时长的原始值，组件禁止直接引用
第 2 层  语义层  --color-* / --font-* / --space-* / --radius-* / --shadow-* / --ease-*
                              组件唯一消费层
第 3 层  组件层  --btn-* / --card-*  可选，只在组件需要独立调优时下沉
```

### 8.2 平滑替换的核心：语义层变量名沿用 v1

这是整个方案的关键决策。v1 的 18 个 CSS 分片里到处是 `--color-bg`、
`--color-text`、`--radius-md`、`--ease-out` 这类语义名。v2 **不改这些名字，只改它们的值**。

结果：绝大多数组件**一行选择器都不用改**，换肤自动生效。要改的只有「值变了以后
比例不再协调」的少数地方（比如卡片内边距从 1.5rem 变 24px）。

新增的第 1 层原始层是纯增量，不影响任何现有文件。

### 8.3 双轨开关（迁移期可 A/B）

迁移期间新旧两套令牌**同时存在**，用 `data-design` 属性切换：

```html
<!-- layouts/partials/head/styles.html -->
<html data-design="{{ .Site.Params.design | default "paper" }}">
```

```css
:root[data-design="paper"] { /* v1 令牌，原封不动 */ }
:root[data-design="prism"] { /* v2 令牌 */ }
```

配合主题现有的深色双通道，最终选择器形如
`:root[data-design="prism"].theme-dark` / `:root[data-design="prism"]:not(.theme-light)`。

好处：一行 `hugo.toml` 配置即可来回切换对照，随时能证明「没改坏」。
迁移全部完成后，删掉 `paper` 那一轨，把 `prism` 提升为默认。

### 8.4 需要新建/改动的文件

| 文件 | 动作 |
| --- | --- |
| `assets/css/primitives.css` | **新增**：第 1 层原始令牌 |
| `assets/css/tokens-prism.css` | **新增**：v2 语义令牌（含浅/深） |
| `layouts/partials/head/styles.html` | 改动：输出 `data-design`、把两个新文件加进 Concat 顺序（放在 fonts 之后、reset 之前） |

## 9. 可访问性底线（v2 必须比 v1 好）

- 正文对比度 ≥ 4.5:1，大字与图形 ≥ 3:1；所有色值在定稿前过一遍 WCAG AA。
- 焦点环 2px + 2px offset，全站可键盘到达。
- 触控目标 ≥ 44×44。
- 所有状态（错误/成功/当前）多重编码，不依赖颜色单独传达。
- `prefers-reduced-motion` 下呈现终态而非零时长动画。
- 首屏内容不依赖 JS（v1 已有这个约束，继承）。
